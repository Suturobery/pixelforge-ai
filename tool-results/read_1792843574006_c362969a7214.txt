    14→    14→## 0 · Change summary (v1.0 → v3.0)
    15→    15→
    16→    16→| Area | Change | Why (trade-off) |
    17→    17→|---|---|---|
    18→    18→| Data model | Per-frame duplicated layer stacks → **per-clip layer stack + per-frame cels** (+ optional linked cels) | Prototype stores every layer in every frame (name-matched fallbacks already required — fragile, storage ×frames). Cels are the Aseprite/Godot standard. Serialized v1 import kept for compatibility. |
    19→    19→| History | Full-layer buffer snapshots (limit 40) → **typed command bus + 16×16 tile-diff entries**, memory budget, undo depth ≥ 250 typical strokes | Prototype caps at 40 because buffers are expensive; tile diffs make deep history cheap. Trade-off: slightly more complex commit path — mitigated by keeping the existing begin/endStroke API shape. |
    20→    20→| Tools | Added: marquee/selection ops, ellipse, pixel-perfect strokes, dither fill, transform ops, palette enforcement | Matches the plan's own "pixel-precise editing" promise; prototype verified missing (Section 10). |
    21→    21→| AI pipeline | Naive NN contain-fit → **normalize pipeline v2** (trim → dominant-color downscale → alpha threshold+despeckle → OKLab quantize → optional outline cleanup) + candidates, presets, cache, cost meter | Prototype pipeline verified working but produces muddy edges on busy art; v2 is deterministic and free. |
    22→    22→| Animation | **Deterministic part-based motion presets as the flagship animation feature**; per-frame durations; loop modes; flicker QA; img2img variations only as Tier-2 review-gated | Directly implements v1 §05 "iterative modifications over independent generation" with an actual mechanism. |
    23→    23→| MCP | 9 REST endpoints → **real MCP server (Streamable-HTTP + stdio proxy)**, pairing, 4 permission tiers, approval queue, ~25 tools, same command bus as UI | The differentiator deserves the full spec; REST catalog + zod schemas port almost 1:1. |
    24→    24→| Files | Prisma/SQLite (web) → **`.pixelforgeproj` ZIP format**: atomic save, journal, backups, provenance, thumbnails | Desktop-first requirement; SQLite stays behind as web-testbed only. |
    25→    25→| Export | PNG/sheet/JSON (kept) + **GIF** + **Godot SpriteFrames `.tres`** promoted to P1 | "Godot-friendly" is a page-1 promise; `.tres` is a text template — cheap. |
    26→    26→| Security | Settings keys in localStorage plaintext → OS keychain via safeStorage, scoped FS, CSP | Desktop attack surface differs from web. |
    27→    27→
    28→    28→Everything else in v1.0 (product definition, personas, workflow, MVP boundaries, risks) is **preserved verbatim unless explicitly amended below**.

    43→    43→## 2 · Desktop pixel art editor — requirements
    44→    44→
    45→    45→### 2.1 Tool set (final P0/P1 list)
    46→    46→| Tool | Spec | Status vs prototype |
    47→    47→|---|---|---|
    48→    48→| Pencil | 1–4 px square stamp, **pixel-perfect decimation** (no L-doubles: skip plotting a corner px when last≠prev and both diagonal neighbors set) | exists; add decimation |
    49→    49→| Eraser | Same stamp, alpha 0 | exists |
    50→    50→| Fill | Scanline flood; toggle **contiguous / global**; secondary-color right-click variant | exists; add global mode |
    51→    51→| Line | Bresenham + stamp; drag preview; Shift = 45° snap | exists; add snap |
    52→    52→| Rect | Filled/unfilled toggle (fill uses secondary) | exists |
    53→    53→| **Ellipse** | Midpoint algorithm + stamp, filled/unfilled | **new (P0)** |
    54→    54→| Eyedropper | Canvas pick; Alt+click shortcut from any tool | exists |
    55→    55→| Move (cel shift) | Shift active cel by drag, integer px, optional wrap | exists (moveBuffer) |
    56→    56→| **Marquee select** | Rect first; ops: move, delete, cut/copy/paste, flip H/V, rotate 90°, nudge; marching-ants outline | **new (P0)** |

    58→    58→
    59→    59→### 2.2 Pixel-perfect drawing
    60→    60→Freehand strokes are recorded as points, then plotted via Bresenham **with L-decimation** (above). Brush >1 px bypasses decimation. Verified as the #1 Aseprite-feel gap in the prototype.
    61→    61→
    62→    62→### 2.3 Palette management & enforcement
    63→    63→- HSV picker with recent colors + shade/tint ramps (prototype has hex + swatches only).
    64→    64→- **Enforcement mode** (project setting, default on): drawing/quantize replaces any out-of-palette color with nearest palette entry (OKLab distance); a status-bar chip shows "out-of-palette: N px" when off.
    65→    65→- Palette import/export: `.gpl`, JASC `.pal`, Aseprite `.hex` (P1). Auto-extract palette from canvas (median cut, ≤64) — **already implemented** in `color.ts quantizeBuffer` (reused).
    66→    66→- Palette ops as commands (undoable): add/remove/reorder/replace-global-color (replace-color = deterministic cel-wide recolor, P1).
    67→    67→
    68→    68→### 2.4 Layers & per-frame cels (model change)
    69→    69→```
    70→    70→Project
    71→    71→└─ Clip (name, fps, loopMode, frames[])
    72→    72→   ├─ LayerStack: Layer[] (bottom→top)     ← defined ONCE per clip
    73→    73→   └─ Frame[] ─ each holds Cel per layer
    74→    74→       Cel { layerId, buffer }             ← missing cel = fully transparent
    75→    75→Layer { id, name, visible, opacity, linked? }
    76→    76→```
    77→    77→- **Linked cels**: a layer can pin all frames to one cel (backgrounds) — cuts storage and "edit once applies everywhere."
    78→    78→- Migration: import SerializedProject **v1** (per-frame layers) → v2 cels by matching layer ids; v1 read support permanent.
    79→    79→- Layer ops (already in prototype, re-targeted to the stack): add, delete, duplicate, merge down (composites cel-wise per frame), reorder, opacity/visibility/name.
    80→    80→
    81→    81→### 2.5 Undo/redo — command history spec
    82→    82→- **Command envelope** `{ id, type, payload, label, timestamp, origin: 'ui'|'mcp'|'ai', undo(): Patch, redo(): Patch }` — MCP and AI call the exact same bus (v1 §03 separation-of-concerns, enforced in code).
    83→    83→- **Pixel edits**: 16×16 **tile diffs** (dirty tiles with before/after bytes), stroke-grouped via existing `beginStroke/endStroke/cancelStroke` contract. Structural edits: shallow snapshots with copy-on-write buffers (prototype mechanism, kept).
    84→    84→- **Budget**: default 64 MB per project (Settings; 16–512); oldest entries evicted; status bar shows usage. Typical 32×32 stroke ≈ 0.5 KB → **thousands of undos** vs prototype's 40 full-buffer entries.
    85→    85→- UI: Undo/Redo buttons (exist) + History panel (P2) with jump-to-state.
    86→    86→
    87→    87→### 2.6 Onion skinning & playback
    88→    88→- Onion: previous/next N (1–3), opacity 25/50%, red/green tint; **prototype's single toggle → configurable** (prev-1 default).
    89→    89→- Playback: fixed-step accumulator + rAF (prototype pattern kept); loop modes `forward | reverse | pingpong`; **per-frame `durationMs` override** (0 = use clip fps); scrubbing + `,` / `.` frame step; Space = play/pause.
    90→    90→
    91→    91→### 2.7 Frame operations
    92→    92→Add (empty/duplicate — **duplicate preserves cels exactly**, prototype bug class already fixed here and ported), delete (keeps layer stack by id — fixes the name-matching workaround), reorder (drag + ←/→ buttons), transform (flip/rotate selection or whole cel).

   111→   111→## 3 · AI generation system
   112→   112→
   113→   113→### 3.1 Provider adapter (evolved from prototype's verified adapter)
   114→   114→```ts
   115→   115→interface AIProvider {
   116→   116→  id: string; kind: 'zai'|'openai-compatible'|'anthropic'|'local'
   117→   117→  capabilities: { img2img: boolean; seed: boolean; mask: boolean; n: boolean }
   118→   118→  generate(req: GenRequest): Promise<GenResult>   // images, cost estimate, timings
   119→   119→  editImage?(req: EditRequest): Promise<GenResult> // img2img / inpaint when supported
   120→   120→}
   121→   121→```
   122→   122→- Ships: **Z.AI built-in**, **OpenAI-compatible** (OpenAI, Gemini OpenAI-dialect, OpenRouter, local ComfyUI/OpenAI-shims) — prototype's dialects verified; **Anthropic** stays chat-only (verified: no image API).
   123→   123→- API keys: OS keychain via `safeStorage` (Electron main); never in plaintext settings files (prototype stores plaintext — fixed on desktop).
   124→   124→- **Job manager** (main process): queue `queued → generating → normalizing → review`, cancel, timeout (120 s, verified needed), retry, concurrency 1 per provider; spend meter + monthly cap; every job logged with model/params/duration.
   125→   125→
   126→   126→### 3.2 Generation flow (candidates, never silent replace — v1 principle, verified implemented, kept)
   127→   127→1. Prompt (+ recipe preset: size, palette, style tags, seed, provider) → 2. generate N thumbnails (n=1–4 when supported; else N jobs) → 3. pick → full-res → 4. **normalize v2** → 5. review dialog (original vs normalized, zoom, re-run with tweaks) → 6. **Import as layer / as new frame / discard** (prototype's three actions, kept verbatim).
   128→   128→- **Cache**: `hash(recipe + seed + model + prompt)` → hits cost nothing; generation history persisted per project (thumbnails + provenance), restorable.
   129→   129→- **Cost controls**: pre-flight estimate ("≈ $0.04 · gpt-image-1"), monthly cap with hard stop, "dry run" showing the exact prompt.
   130→   130→
   131→   131→### 3.3 Deterministic normalize pipeline v2 (replaces prototype's contain-fit NN)
   132→   132→Order matters; each step pure & unit-testable (golden-image tests):
   133→   133→1. **Trim** to content bbox (alpha/color border flood).
   134→   134→2. **Dominant-color grid downscale** to target WxH: per target cell take the modal color of the source block (center-weighted, ties → closest to block mean). *Why not plain NN (prototype):* NN aliases detail into noise on downscale >2×; dominant-color yields clean sprite reads. (A/B test gated in P1, §8 benchmarks.)
   135→   135→3. **Alpha threshold** (<128 → 0) + **despeckle** (remove isolated single opaque px).
   136→   136→4. **Background removal**: border flood-fill with tolerance (prototype algorithm, kept, already good).
   137→   137→5. **OKLab quantize** to project palette (or auto median-cut ≤64 when "free palette"); dithering **off** by default.
   138→   138→6. Optional 1-px outline cleanup (remove AA fringe: out-of-palette px adjacent to transparency).
   139→   139→All steps run off the main thread (Worker). Provider-independent ⇒ identical output across providers, free to re-run.
   140→   140→
   141→   141→### 3.4 Provenance
   142→   142→Every candidate stores `{model, providerId, prompt, seed?, params, timestamp, jobDurationMs}` — shown in review UI, persisted in project file (`provenance/ai/`), reused by "regenerate similar."

   146→   146→## 4 · AI animation — realistic workflow
   147→   147→
   148→   148→> Preserved from v1.0: no promise of one-prompt production animation. **Mechanism below is the v3 addition.**
   149→   149→
   150→   150→### 4.1 Tier 1 — Part-based motion presets (flagship, P1)
   151→   151→- Character = base sprite; optional **part tags** (head/body/armL/armR/legL/legR) via marquee → "Tag part" (stores region, not a cut). Parts may also be separate layers (AI can generate part variants).
   152→   152→- Presets = parametric transform curves per part, composed into new cels:
   153→   153→| Preset | Frames | Curve (32×32 reference, scales with canvas) |
   154→   154→|---|---|---|
   155→   155→| idle-bob | 4 | body dy = [0,−1,−2,−1]; head dy = body; hair/coat 1-frame lag |
   156→   156→| walk | 4/6/8 | legL/legR alternate dx ±3, dy [0,−1]; body bob dy [0,−1,0,1]; arm counter-swing |
   157→   157→| run | 6 | walk amplitude ×1.5, forward lean dx +1, dy arc |
   158→   158→| attack | 4–6 | armL arc keyframes (raise→swing→recover), 1-px smear frame option |
   159→   159→| jump | 6 | dy parabola, squash [1,2] px on takeoff/land |
   160→   160→- **Composition is undoable, deterministic, $0**; every generated frame remains a normal editable cel; presets can be re-applied/re-parameterized ("amplitude", "hold frames").
   161→   161→- Verification hooks: side-by-side before/after, per-frame diffs.
   162→   162→
   163→   163→### 4.2 Tier 2 — AI frame variations (P2, review-gated)
   164→   164→img2img: frame N as init (strength 0.25–0.45, seed locked, recipe attached) → normalize v2 → **pixel-diff overlay vs frame N** → user accepts/edits/discards. Suited to breathing/blink/tail-wag deltas. Never auto-chained without review.
   165→   165→
   166→   166→### 4.3 Tier 3 — Experimental (P3, flagged)
   167→   167→Video-model → pixelize pipelines; dedicated pixel-animation services. Behind "Experimental" settings flag; excluded from marketing claims.
   168→   168→
   169→   169→### 4.4 Consistency QA tools (P1)
   170→   170→- **Reference lock**: pin frame 1 as ghost + baseline guide + facing arrow; every new frame request auto-attaches it.
   171→   171→- **Flicker detector**: per-frame pixel-diff heatmap + "jitter score" (changed-px count vs threshold); failing frames highlighted in timeline.
   172→   172→- **Anchor overlay**: ground line + center axis; onion skins (§2.6).
   173→   173→- **Review workflow**: animation strip view with per-frame accept/revert; nothing enters the clip without explicit commit.

   177→   177→## 5 · MCP integration specification
   178→   178→
   179→   179→### 5.1 Topology
   180→   180→```
   181→   181→Claude/Cursor/etc ──stdio──▶ mcp-stdio-proxy ──▶ PixelForge app (127.0.0.1:<port>)
   182→   182→             └────────Streamable-HTTP (native clients)──────────┘
   183→   183→                                   │ in-process
   184→   184→                            Command Bus ──▶ Editor core (same as UI)
   185→   185→```
   186→   186→- **Streamable-HTTP MCP** inside the Electron main process (official TS SDK); **stdio proxy** (~80 LOC) for spawn-based clients. Loopback bind only.
   187→   187→- **Pairing**: Settings → "Connect assistant" → 6-word one-time token; client's first call presents it; client stored in allowlist with a permission tier; revocable list UI.
   188→   188→
   189→   189→### 5.2 Permission tiers
   190→   190→| Tier | Ops | Approval |
   191→   191→|---|---|---|
   192→   192→| L0 read | get_project_state, list_projects, get_clip, get_frame_png, get_palette, get_operation_log, preview_animation, subscribe_events | none after pairing |
   193→   193→| L1 safe write (undoable) | add/duplicate/reorder/delete-frame*, set_pixels, fill_rect, replace_color, flip/rotate/shift, add_clip, add_palette_color, undo, redo, import_image_as_layer, apply_normalize | auto |
   194→   194→| L2 destructive / disk | delete_layer/clip, resize_canvas, save_project (as), export_* | approval card (visual diff) or per-session grant |
   195→   195→| L3 spends money | generate_sprite, apply candidates, Tier-2 variations | approval card + quota check |
   196→   196→
   197→   197→*delete-frame stays L1 because undoable; permanent purge (empty trash) is L2.
   198→   198→
   199→   199→### 5.3 Tool catalog (schemas: zod in prototype verified — re-used and extended)
   200→   200→Envelope: `input: <zod>`; `output: { ok, error?: {code, message, hint}, data, undoable, requiresApproval?, stateHash }`. `stateHash` (xxhash of doc tree) lets agents detect staleness instead of blind re-polls.
   201→   201→
   202→   202→**Read (L0):** `get_project_state` (verified in prototype; extended: clips+layers+cels+selection+settings) · `list_projects` · `open_project` · `get_clip` · `get_frame_png` (base64/thumbnail) · `get_palette` · `get_operation_log` (verified: SQLite OperationLog ported to JSONL in project dir) · `subscribe_events` (SSE: `projectChanged(stateHash)`, `jobUpdate`, `approvalRequested`).
   203→   203→
   204→   204→**Safe write (L1):** `add_frame`, `duplicate_frame`, `reorder_frames`, `delete_frame`, `set_pixels` (prototype: bounds-checked, ≤2000 px — kept; adds layerId + selection-clip), `fill_rect`, `replace_color`, `flip_frame`/`rotate_frame`/`shift_frame`, `add_clip`, `set_clip_props` (fps/loopMode), `add_palette_color`/`set_palette`, `import_image_as_layer`, `apply_normalize`, `undo`, `redo`, `set_selection`? (no — selection is UI-local; tools address layers/cels directly).
   205→   205→
   206→   206→**AI (L3):** `generate_sprite` → returns **candidate ids + thumbnails, does NOT import** (fixes prototype behavior where MCP generate imported directly); `get_candidates`/`accept_candidate`/`reject_candidate`; `suggest_motion_preset` (proposes preset params from prompt; pure function, L0 cost).
   207→   207→
   208→   208→**Destructive/export (L2):** `delete_layer`, `delete_clip`, `resize_canvas` (explicit data-loss warning in schema description), `save_project` (`as` path), `export_frames`/`export_spritesheet`/`export_metadata`/`export_gif`/`export_godot`.
   209→   209→
   210→   210→### 5.4 Approval workflow
   211→   211→L2/L3 call → `requiresApproval: true, approvalId` → **Agent Review card in-app** (side-by-side diff, params, cost) → Approve/Approve-session/Deny → tool resolves with result or `denied` error. Timeouts (120 s) return structured `pending_approval`; agents may poll `get_operation_log` or subscribe.
   212→   212→
   213→   213→### 5.5 Security
   214→   214→Loopback-only bind; token pairing + allowlist + revocation; per-tier rate limits (60 rpm L0, 30 rpm L1, 10 rpm L2/L3); request body ≤ 2 MB; FS confined to project dir + user-picked export dir; no shell, no arbitrary URL fetch from tool handlers; audit log (who/when/tool/params-hash/result/duration) persisted per project; security tests in §8. **All tool calls execute through the command bus** — one validation surface, full undo integration (v1 §04 rule, now structural).

   218→   218→## 6 · Project file format — `.pixelforgeproj`
   219→   219→
   220→   220→```
   221→   221→farmer.pixelforgeproj          # ZIP (store/deflate, deterministic entry order)
   222→   222→  manifest.json                # { formatVersion: 2, appVersion, createdAt, updatedAt,
   223→   223→                               #   checksums: { "project.json": sha256, ... } }
   224→   224→  project.json                 # document (schema below)
   225→   225→  cels/<clipId>/<frameId>/<layerId>.png
   226→   226→  thumbs/<clipId>/<frameId>.png          # 64px — timeline + MCP previews
   227→   227→  provenance/ai/<jobId>.json             # §3.4 records
   228→   228→  history/journal.jsonl                  # recent commands for crash recovery
   229→   229→```
   230→   230→```jsonc
   231→   231→// project.json (schema v2 — v1 auto-imported)
   232→   232→{
   233→   233→  "schemaVersion": 2, "name": "farmer", "width": 32, "height": 32,
   234→   234→  "palette": ["#1a1c2c", "..."],           // + per-color metadata (name?) optional
   235→   235→  "layers": [{ "id": "ly1", "name": "body", "visible": true, "opacity": 1, "linked": false }],
   236→   236→  "clips": [{
   237→   237→    "id": "cl1", "name": "idle", "fps": 8, "loopMode": "forward",
   238→   238→    "frames": [{ "id": "fr1", "durationMs": 0, "cels": { "ly1": "cels/cl1/fr1/ly1.png" } }],
   239→   239→    "tags": []                              // P1: { name, from, to }
   240→   240→  }],
   241→   241→  "settings": { "paletteEnforce": true, "onion": { "prev": 1, "next": 0 } }
   242→   242→}
   243→   243→```
   244→   244→- **Atomic save**: write `<name>.tmp` → fsync → rename; journal records last 200 commands; on open, journal replay offered if newer than file.
   245→   245→- **Backups**: on open-after-crash + every 10 min if dirty → `backups/<timestamp>.pixelforgeproj`, keep 5 (Settings).
   246→   246→- **Buffers**: runtime `Uint8ClampedArray` (v3 keeps prototype's buffer type; palette-indexed storage explored in P2 only if 256×256 memory becomes an issue).
   247→   247→- Prototype's Prisma/SQLite rows remain the **web-testbed** store; desktop builds import/export the same SerializedProject v1 JSON, then v2.

   269→   269→### 8.1 Stack verdict (v1 stack preserved; roles sharpened)

   297→   297→## 9 · Performance & reliability
   298→   298→
   299→   299→### 9.1 Budgets (CI-enforced)
   300→   300→| Metric | Budget |
   301→   301→|---|---|
   302→   302→| Open 256×256 × 24-frame project | < 300 ms |
   303→   303→| Pan/zoom | 60 fps @ 8× zoom |
   304→   304→| Playback | 60 fps (dirty-rect compositing) |
   305→   305→| Undo memory | ≤ 64 MB default (16–512 setting) |
   306→   306→| Autosave pause | < 100 ms off-UI-thread |
   307→   307→| Cold start | < 2 s |
   308→   308→| Installer | < 120 MB |
   309→   309→
   310→   310→### 9.2 Memory & rendering strategy
   311→   311→- Tile-diff history (§2.5); cel PNGs stored once, decoded lazily; LRU decode cache (default 128 MB); Worker compositing for playback/export; dirty-rect repaint (prototype's full-canvas repaint acceptable ≤64×64, replaced above).
   312→   312→- **AI cancellation**: AbortController end-to-end (prototype's 120 s timeout kept; cancel button added); queue jobs drop cleanly at any state.
   313→   313→
   314→   314→### 9.3 Error recovery
   315→   315→Atomic save + journal replay + backups (§6); export writes temp + rename; crash reporter captures last 100 commands (local); unsaved-changes guard on quit; MCP approval timeout → structured pending (§5.4).
   316→   316→
   317→   317→### 9.4 Testing
   318→   318→- **core unit tests**: command bus (undo round-trip incl. mid-stroke structural edits), pixel ops, normalize golden images, exporters golden files, file-format migration v1→v2.
   319→   319→- **MCP contract tests**: schema validation per tool, permission-tier enforcement, approval timeout, pairing.
   320→   320→- **E2E (Playwright over renderer)**: draw→undo→save→kill -9→reopen→identical; generate→review→import; motion preset→edit cel→export.
   321→   321→- **Security tests**: path traversal on save-as/export, token rejection, oversized payloads, loopback-only bind verification.
   322→   322→- **Benchmarks**: §9.1 budgets asserted in CI (headless timing harness).
   323→   323→- **Packaging**: electron-builder (NSIS, Win first), code-signing cert pipeline, **electron-updater** staged rollout; crash telemetry opt-in only, local by default.
